# The Angler project guidance

Before changing this project, read `docs/PROJECT-CORE.md`. For conceptual writing, exhibition labels, README changes, assessment material or artist statements, also consult the local source proposal at `docs/private-reference/Computational Arts Summer Final Project Proposal.pdf` when it is available.

The private proposal contains personal information. Never commit it, quote the student ID or email, or include either item in public-facing material.

Preserve existing dirty-worktree changes and valid assets. Do not replace or regenerate working visual or audio assets unless the user explicitly requests it. After changing the running experience, test the real page at `http://localhost:3001`, inspect the visible result and browser console, and leave the local service running.
