# The Angler: Beneath the Surface?

A screen-based interactive artwork using lure fishing as a metaphor for AI prompting and judgement.

## Current Goal

Build the first working prototype:

```text
choose conditions -> enter a question -> cast -> receive AI response -> show visual catch -> try again
```

## Structure

```text
docs/              image references and sketches
public/fonts/      font files
public/sounds/     sound files
index.html         main page
sketch.js          p5.js sketch
style.css          page style
app.js             API / app logic
```
