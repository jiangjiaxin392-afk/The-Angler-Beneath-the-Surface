# Concept Notes

## Working Title

*The Angler: Beneath the Surface?*

## One-Sentence Description

A screen-based interactive artwork that uses lure fishing as a procedural metaphor for asking questions through AI.

## Key Terms

- Lure fishing
- Prompting
- Response vs answer
- Partial knowledge
- Uncertainty
- Judgement
- Feedback loop
- Visual catch

## Important Distinction

The project does not compare fish and AI as the same kind of entity. It compares the user's position in two interaction processes.
