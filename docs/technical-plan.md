# Technical Plan

## Minimum Prototype

The first prototype should connect:

```text
condition selection -> prompt construction -> AI response -> visual catch -> retry
```

## Planned Components

- Visual water interface
- Question input
- Condition selection
- Cast action
- AI response request
- Response classification
- Visual catch display
- Retry / adjust loop

## Possible Tools

- p5.js
- JavaScript
- OpenAI API
- Optional: TouchDesigner for later visual development

## Main Risks

- API delay
- Internet access
- Response inconsistency
- The work being read as a normal fishing game

## Backup Plan

Use saved or pre-generated responses if the live API is unstable.
