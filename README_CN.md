# 垂钓者：水面之下？

**Computational Arts Final Project**

这个仓库用于整理毕业项目 *The Angler: Beneath the Surface?* 的开发文件。项目是一个基于屏幕的互动艺术作品，使用路亚垂钓的过程来探讨人如何向 AI 提问、接收不确定回应，并判断这些回应意味着什么。

## 项目简介

作品计划以屏幕互动装置的形式呈现。观众进入一个类似钓鱼的数字界面，选择地点、天气、目标鱼、拟饵类型、收线方式等条件，并输入一个问题或意图。这些选择会共同构成发送给 AI 系统的 prompt。

AI 的回应会被转化为一个视觉“钓获”。这个钓获可能是有用的、部分有用的、误导性的、无关的、非目标的，或空的。观众随后需要判断：接受这个结果、拒绝它、调整条件，或再次尝试。

## 核心问题

当人可以影响一个回应，却无法完全知道或控制这个回应如何产生时，人如何作出判断？

## 核心概念

项目并不主张鱼和 AI 系统是相同的。作品比较的是两种互动过程中的结构：

1. 准备
2. 抛投
3. 等待
4. 接收回应
5. 判断结果
6. 调整并再次尝试

这个结构用于放慢人向 AI 寻求答案的过程。作品想强调：AI 的 response 不会自动成为 answer，它仍然需要人的解释、判断和责任。

## 计划中的交互循环

```text
观众选择
  -> prompt 构建
  -> OpenAI API 回应
  -> 回应分类
  -> 视觉钓获
  -> 观众判断
  -> 下一次尝试
```

## 当前技术方向

- 屏幕互动界面
- 鼠标和键盘操作
- p5.js / JavaScript 原型
- OpenAI API 生成回应
- 将回应转化为视觉钓获的反馈系统
- 备用方案：使用保存或预生成的回应

## 当前阶段

早期开发阶段。第一步目标是制作一个最小可运行原型，先跑通：

```text
条件选择 -> prompt -> AI 回应 -> 视觉钓获 -> 再次尝试
```
